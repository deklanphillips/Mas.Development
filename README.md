# MAS Soccer Development — Website

One-page website for [@mas.development](https://www.instagram.com/mas.development/), a 1-on-1 soccer training business.

## What's here

- `index.html` — the entire site (HTML + CSS in one file, no build step required)

## Sections

- Hero — "Train More. Save More." with booking call-to-action
- Why MAS — the four training pillars (Personalized, Skill Development, Performance, Confidence)
- Pricing — session packages (2/4/6/8/10 sessions) with savings
- How It Works — booking via Instagram DM
- July special banner

## Running / hosting

It's a single static file — open `index.html` in any browser, or host it for free with GitHub Pages (Settings → Pages → deploy from branch).
